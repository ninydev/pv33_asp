Папка: Views/Shared (Area: Task)

Назначение
- Общие для области Task частичные представления (partials), layout'ы и элементы UI.

Что размещать
- Частичные представления, используемые несколькими страницами области, например: `_TaskNav.cshtml`, `_TaskListItem.cshtml` и т. п.
- Вспомогательные UI-компоненты и секции.

Замечания
- Глобальные layout'ы и partials приложения хранятся в `~/Views/Shared`. Если требуется общий макет для области, можно создать свой и указать его в `_ViewStart.cshtml`.
